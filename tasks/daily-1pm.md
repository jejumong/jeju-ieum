예약 작업은 이 파일을 읽고 아래 순서를 그대로 수행합니다.

- 작업 1: 제주이음(https://jejuieum.com)의 **열두 달 달력 마을 행사**를 갱신합니다.
- 작업 2: **축제정보** 게시판을 갱신합니다.
- 보고: 사용자(김민)에게 한국어로 짧게 알립니다.
- 클라우드에서만 돌기 때문에 브라우저 도구는 쓰지 않습니다. 웹 자료는 WebSearch(필요하면 mode "extended")와 WebFetch 로만 찾습니다.

## 1. 열두 달 달력 마을 행사 (`calendar/index.html`)
### 1-1. 고칠 곳
- 스크립트 안의 `/*LOCAL_EVENTS_START*/` ~ `/*LOCAL_EVENTS_END*/` 블록만 고칩니다.
- 아래 부분은 절대 건드리지 않습니다:
  - 그 밖의 코드, 디자인, 기존 E 배열
  - 머리말, 구글 애널리틱스
  - "‹ 제주몽 홈" 버튼(jjm-bar)
  - 제주이음 안에 넣어 볼 때 쓰는 코드
- 블록 형식: `const LAST_UPDATED="YYYY-MM-DD"; const LOCAL=[ {s:"시작일",e:"끝일",w:[요일번호](선택),t:"이름",d:"설명 1~2문장",p:"장소",tip:"관광객용 요령(선택)",u:"출처 URL"}, ... ];`
  - w 는 매주 특정 요일에만 열리는 행사에 씁니다(0=일 ~ 6=토).
  - d 에는 시간·요금 같은 정보를, p 에는 주소를 우선으로 씁니다.

### 1-2. 정리
- 끝일(e)이 오늘(Asia/Seoul)보다 이전인 행사는 지웁니다.
- 사흘 안에 시작하거나 진행 중인 행사는 날짜·장소 변경이나 취소 소식을 한 번 검색해 봅니다. 취소됐으면 지웁니다.
- u 가 금지 사이트면, 같은 행사를 다룬 기사나 공식 안내로 바꿉니다.

### 1-3. 새 행사 찾기
- 찾을 행사:
  - 오늘부터 약 6주 안에 제주에서 열리는 마을·소규모 행사입니다.
  - 관광객이 참여하거나 구경할 수 있어야 합니다.
  - 최근 2~3일 사이에 새로 보도되거나 공지된 것을 중심으로 봅니다.
  - 예: 마을 축제, 포구·해변 행사, 플리마켓, 체험 박람회, 목장·농장 축제, 걷기·자전거 행사, 원도심 공연, 도서관·미술관 체험, 연말 해넘이·새해 행사.
- 검색:
  - 검색어 예: "제주 이번 주말 행사", "제주 ○월 축제 개최", "서귀포 ○월 행사", "제주시 ○○읍 축제", "제주 플리마켓 ○월".
  - 먼저 볼 출처: 헤드라인제주, 제주일보, 제주의소리, 뉴스제주, 미디어제주, 제주도민일보, 한라일보, 비짓제주, 제주인놀다.
- 넣지 않는 것:
  - E 배열에 이미 있는 큰 축제(감귤박람회, 방어축제, 올레걷기축제, 탐라문화제 등)
  - 이미 LOCAL 에 있는 행사
  - 참가자 모집 공고, 공무원·업계 전용 행사, 학술 세미나
- 추가·삭제·수정한 것이 있을 때만 LAST_UPDATED 를 오늘 날짜로 바꿉니다.

### 1-4. 검증
- `calendar/index.html` 의 가장 긴 `<script>` 를 `node --check` 로 문법 검사합니다.
- grep 으로 jjm-bar 가 그대로 있는지 확인합니다.
- grep 으로 LOCAL 블록에 금지 사이트가 없는지 확인합니다.

## 2. 축제정보 (`assets/festivals-data.js`)
- 축제정보 게시판(https://jejuieum.com/festivals.html)의 축제 목록은 이 파일의 FESTIVALS 배열에서 나옵니다.
- 파일 맨 위 주석에 항목 설명이 있습니다.
- FESTIVALS 배열과 FESTIVALS_CHECKED 만 고치고, 아래쪽 끼워 넣기 코드는 건드리지 않습니다.

### 2-1. 정리
- 이미 있는 축제는 다음을 확인합니다:
  - 날짜·장소 변경
  - 취소
  - 세부 프로그램·요금 발표
- 바뀐 것이 확인되면 해당 필드만 고칩니다.
- **id 는 절대 바꾸지 않습니다.**
- 끝난 지 7일이 지난 축제는 화면에서 자동으로 빠지므로 그대로 둡니다. 단, 끝난 지 60일이 지난 항목은 지워서 파일을 가볍게 합니다.

### 2-2. 새 축제 찾기
- 찾을 축제:
  - 오늘부터 약 8주 안에 제주에서 열리는 축제·큰 행사입니다.
  - 달력 마을 행사와 달리 큰 축제도 넣습니다.
  - 예: 성산일출축제, 해넘이 축제, 동백·빛 축제, 감귤·방어 축제, 문화제, 박람회, 야시장, 공연 축제.
- 검색어 예: "제주 축제 ○월 개최", "서귀포 축제 개막", "제주시 축제 일정 발표", "제주 해넘이 축제 2026", "성산일출축제 일정".
- 이미 FESTIVALS 에 있는 축제는 제목·장소·기간을 비교해 중복으로 넣지 않습니다.
- 새 항목 작성법:
  - **id**: "rf" + 기존 가장 큰 번호 다음 숫자. 예: rf17 다음은 rf18.
  - **title**: 축제 이름.
  - **content**: 확인된 내용 2~4문장. 마지막 문장은 "자세한 안내: <출처 URL>".
  - **date**: 오늘 날짜.
  - **loc**: 장소.
  - **start, end**: 기간.
  - **emoji**: 이모지 하나.
  - **위치**: px/py 를 모르면 넣지 않고, 대신 lat, lng(위도·경도 숫자)를 넣습니다. 둘 다 모르면 둘 다 뺍니다.
- 바뀐 게 없어도 FESTIVALS_CHECKED 를 오늘 날짜로 바꿉니다. 화면에 '최근 확인' 날짜로 나옵니다.

### 2-3. 검증
- 아래 명령으로 문법과 id 중복을 확인합니다. 실패하면 고칩니다.

```
node -e "global.window=global;var TRADE_SEEDS=[],SEED_POSTS=[];eval(require('fs').readFileSync('assets/festivals-data.js','utf8'));var ids=FESTIVALS.map(f=>f.id);if(new Set(ids).size!==ids.length)throw 'id 중복';console.log('OK',ids.length)"
```

## 3. 반영
- `calendar/index.html` 과 `assets/festivals-data.js` 두 파일만 커밋합니다.
- 커밋 메시지: "달력·축제 갱신 YYYY-MM-DD"에 바뀐 항목 요약을 붙입니다.
- 사용자 요청에 따라 main 브랜치에 바로 올립니다: `git pull --rebase origin main` 후 `git push origin HEAD:main`.
- push 하면 GitHub Pages 로 사이트에 자동 반영됩니다.
- push 가 거부되면:
  - 저장소 접근을 우회하거나 새로 얻으려 하지 않습니다.
  - 고친 파일을 SendUserFile 로 보내고, 거부 메시지 한 줄을 함께 적습니다.
