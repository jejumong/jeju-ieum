# 열두 달 달력 · 마을 행사 매일 갱신 (예약 작업 지시서)

이 파일은 매일 오후 1시쯤 도는 예약 작업이 읽고 그대로 수행하는 지시서입니다.

- 대상 페이지: 관광객용 '제주 열두 달 달력'(`calendar/index.html`, https://jejuieum.com/calendar/)
- 하는 일: "마을 행사" 목록에서 새 소식을 찾아 갱신합니다.
- 보고: 사용자(김민)에게 한국어로 짧게 보고합니다.
- 실행 환경: 클라우드에서만 돌기 때문에 브라우저 도구는 쓰지 않습니다.

## 1. 저장소 준비
- 이 작업에는 jejumong/jeju-ieum 저장소가 연결되어 있습니다. 작업 폴더에서 찾고(`git remote -v`), main 을 최신으로 맞춥니다(`git checkout main && git pull`).

## 2. 고칠 곳
- `calendar/index.html` 스크립트 안의 `/*LOCAL_EVENTS_START*/` ~ `/*LOCAL_EVENTS_END*/` 블록만 고칩니다.
- 아래 부분은 절대 건드리지 않습니다.
  - 그 밖의 코드와 디자인
  - 기존 E 배열
  - 머리말
  - 구글 애널리틱스
  - "‹ 제주몽 홈" 버튼(jjm-bar)
  - 제주이음 안에 넣어 볼 때 쓰는 코드
- 블록 형식: `const LAST_UPDATED="YYYY-MM-DD"; const LOCAL=[ {s:"시작일",e:"끝일",w:[요일번호](선택),t:"이름",d:"설명 1~2문장",p:"장소",tip:"관광객용 요령(선택)",u:"출처 URL"}, ... ];`
  - w: 매주 특정 요일에만 열리는 행사에 씁니다(0=일 ~ 6=토).
  - d: 시간·요금 같은 정보를 넣습니다.
  - p: 주소를 우선으로 씁니다.

## 3. 정리
- 끝일(e)이 오늘(Asia/Seoul)보다 이전인 행사는 지웁니다.
- 사흘 안에 시작하거나 진행 중인 행사는 날짜·장소 변경이나 취소 소식을 한 번 검색해 봅니다. 취소됐으면 지웁니다.
- u 가 아래 [링크 규칙]에서 금지한 사이트면, 같은 행사를 다룬 신문 기사나 공식 안내 주소로 바꿉니다.

## 4. 새 행사 찾기
WebSearch(필요하면 mode "extended")와 WebFetch 를 씁니다.

**찾을 행사**
- 오늘부터 약 6주 안에 제주에서 열리는 마을·소규모 행사 가운데 관광객이 참여하거나 구경할 수 있는 것을 찾습니다.
- 최근 2~3일 사이에 새로 보도되거나 공지된 것을 중심으로 봅니다.
- 예: 마을 축제, 포구·해변 행사, 플리마켓, 체험 박람회, 목장·농장 축제, 걷기·자전거 행사, 원도심 공연, 도서관·미술관 체험, 연말 해넘이·새해 행사.

**검색 방법**
- 검색 예: "제주 이번 주말 행사", "제주 ○월 축제 개최", "서귀포 ○월 행사", "제주시 ○○읍 축제", "제주 플리마켓 ○월".
- 먼저 볼 출처: 헤드라인제주, 제주일보, 제주의소리, 뉴스제주, 미디어제주, 제주도민일보, 한라일보, 비짓제주, 제주인놀다.

**넣는 기준**
- 올해 날짜와 장소가 기사나 공식 안내로 확인된 것만 넣습니다. 작년 일정이나 추측한 날짜는 넣지 않습니다.
- 다음은 중복으로 넣지 않습니다.
  - 이미 E 배열에 있는 큰 축제(감귤박람회, 방어축제, 올레걷기축제, 탐라문화제 등)
  - 이미 LOCAL 에 있는 행사
- 참가자 모집 공고, 공무원·업계 전용 행사, 학술 세미나처럼 관광객이 갈 수 없는 것은 뺍니다.

**쓰는 방법**
- 설명은 관광객이 바로 이해할 쉬운 존댓말 1~2문장으로 씁니다.
- 큰따옴표는 쓰지 않고, 문자열 안에 백슬래시나 백틱을 넣지 않습니다.
- 추가·삭제·수정한 것이 있을 때만 LAST_UPDATED 를 오늘 날짜로 바꿉니다. 아무 변화가 없으면 6을 건너뛰고 7로 갑니다.

### 링크 규칙 (사용자 요청)
- u 에는 다음만 넣습니다: 신문사 기사, 비짓제주(visitjeju.net), 제주도·제주시·서귀포시 누리집, 주최 측 공식 홈페이지.
- 축제 모음·축제 달력 사이트는 절대 링크하지 않습니다: recomarea.com, 축제닷컴(xn--ok0b236bp0a.com), festival.peoplentools.com, tamraoo.com, month2k.com, travelmapjourney.com, ktriptips.com 등.
- 이런 사이트는 행사를 찾는 데만 참고합니다. 링크는 같은 행사를 다룬 기사나 공식 안내를 따로 찾아 넣고, 그런 출처를 못 찾으면 그 행사는 넣지 않습니다.

## 5. 검증
- `calendar/index.html` 의 가장 긴 `<script>` 내용을 `node --check` 로 문법 검사합니다. 통과해야만 다음으로 넘어갑니다.
- grep 으로 두 가지를 확인합니다.
  - jjm-bar 가 그대로 있는지
  - LOCAL 블록에 금지 사이트 주소가 없는지

## 6. 반영
### (a) 제주이음
- `calendar/index.html` 만 커밋합니다(메시지 "마을 행사 갱신 YYYY-MM-DD").
- git 사용자 이름·메일이 없으면 이 저장소에서만 "Claude" / noreply@anthropic.com 으로 설정합니다.
- 사용자 요청에 따라 main 브랜치에 바로 올립니다: `git pull --rebase origin main` 후 `git push origin HEAD:main`.
- push 가 거부되면 저장소 접근을 우회하거나 새로 얻으려 하지 않습니다. 대신 고친 `calendar/index.html` 을 SendUserFile 로 보내고, 거부 메시지 한 줄을 함께 적습니다.

### (b) 사용자 개인 사본 (Claude 아티팩트)
- 대상: https://claude.ai/artifact/X1bFiUqP6pEZewcuHsp4t4
- 순서:
  1. Artifact 도구 action "read" 로 읽고, path "index.html" 로 파일을 내려받습니다.
  2. 그 파일의 LOCAL_EVENTS 블록만 (a)와 같은 내용으로 바꿉니다.
  3. `node --check` 가 통과하면 같은 url 로 publish 합니다(icon 은 넘기지 않음).
- 실패해도 (a)는 그대로 둡니다.
